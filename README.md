# Reroute

A public-transport-first trip planner for Brisbane and South East Queensland: a PWA with a Flask back end and a React shell, plus Capacitor projects for the app stores.

Started in 2026 as a UQ COMP1100 team project (team 45). This repository continues the app on its own; the course research material (interviews, canvases, prototypes) stays in the course repository and is not included here.

- App, setup and commands: [`apps/plan-b-mvp/README.md`](apps/plan-b-mvp/README.md)
- Engineering docs: [`docs/engineering/`](docs/engineering/README.md)
- Product docs and feature logs: [`docs/product/`](docs/product/README.md)
- Deployment: [`infra/`](infra/README.md)

`make check` runs what CI runs.
