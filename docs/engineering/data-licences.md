# Data and software licences

Written by Claude Sonnet 5.5 via Claude Code at T.P's request, 2026-10-28. **Human review required:** this is a reading of public licence names, not legal advice, and no licence page was fetched while writing it.

The in-app page is `/licences` (`web/src/screens/legal/licences.body.jsx`); the package list is generated by `node web/scripts/gen-licences.mjs` from `package-lock.json` (production packages only) and the installed Python dependency closure of `requirements.txt`. Re-run it after any dependency change and commit `licences.data.json`.

## Data and services

| Translink GTFS and GTFS-Realtime | Creative Commons Attribution 4.0 International (CC BY 4.0) | Same, with the "contains data from Translink, Queensland Government" credit and a note that the data was changed | **Mismatch to resolve.** The task brief called it the "Queensland Open Data licence"; the app text says CC BY 4.0. ## Software

Generated rows list name, version, the declared licence and the first copyright line from the licence file. The shipped JavaScript is permissive (MIT, ISC, 0BSD, MPL-2.0 for `@capacitor/*` pieces where declared). Items for review: `pywebpush` and `py-vapid` are MPL-2.0 and `certifi` is MPL-2.0 (file-level copyleft; fine when unmodified); `cryptography` is Apache-2.0 or BSD; GSAP (vendored in `vendor/`) is under GreenSock's own standard licence, not an OSI licence (free for this use as of the 3.12 licence text, but confirm the current terms, especially if the app is monetised). The page links to each package's source for the full licence text rather than embedding every text; MIT and BSD licences ask for the notice to accompany copies, so a stricter reading may require embedding the texts in the native build's settings screen. That is a decision for the team.
